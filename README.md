# SolidEuclid

SolidEuclid is a high-performance, cross-platform geometric modeling kernel written in Rust. It provides a robust foundation for generating precise 3D primitives, applying advanced edge treatments, and performing Constructive Solid Geometry (CSG) operations.

Designed with portability in mind, SolidEuclid offers first-class support for C++ via a C-bridge and TypeScript/JavaScript through WebAssembly (WASM).
